# Lubu Folio

An interactive developer portfolio with 3D experiences, animations, and immersive themed pages. Built with Astro, React, Three.js, and GSAP.

## Sections

- **Portfolio** — hero, about, project showcase, skills constellation (3D visualization), experience timeline, and contact
- **Hub** — central navigation with interactive elements
- **Arcade** — interactive gaming experience
- **Construct** — creative building tool
- **Grid, SSH, Through Her Eyes, Void** — experimental and thematic pages

## Features

- 3D graphics with Three.js and React Three Fiber
- Smooth scroll-driven animations via GSAP
- Custom cursor and keyboard commands
- Achievement toast notifications
- Theme switcher with multiple visual modes
- Section observer for scroll-triggered effects
- Audio integration with Howler.js
- Responsive navigation with dot indicators
- State management with Zustand

## Tech stack

- **Astro 5** for static site generation and routing
- **React 19** for interactive components
- **Three.js** / React Three Fiber / Drei for 3D
- **GSAP** for animations
- **Tailwind CSS 4** for styling
- **Howler.js** for audio
- **Zustand** for state management

## Run locally

```bash
git clone https://github.com/L-ubu/Lubu-Folio.git
cd Lubu-Folio
npm install
npm run dev
```

Opens at `localhost:4321`.
